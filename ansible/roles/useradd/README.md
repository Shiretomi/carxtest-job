Add user
=========

Добавляет пользователя с паролем в систему

Переменные
--------------

```
useradd_user: carxadmin        # Имя пользователя на хосте
useradd_pass_hash: some_hash   # Требуется передать хэш пароля, либо ссылку на переменную из vault
```

Использование в плейбуке
----------------
```
- hosts: all
  roles:
    - useradd
```
