Setup nginx
=========

Подключает репозиторий, скачивает и конфигурирует nginx, добавляет базовую страничку

Переменные
--------------
```
setup_nginx_webroot: /var/www/html        # дирекотрия для вебрута 
```
Использование в плейбуке
----------------
```
- hosts: all
  roles:
    - setup_nginx
```
