# Webapp-proxy микросервис
Простенький пересобранный **alpine nginx** последней версии.

Образ пересобирается, удаляя стандартный `default.conf` и вместо него через шаблон подставляется нужный конфиг с нужными переменными.

Для запуска требуется передать переменные
```
APP_SERVICE_HOST=localhost
APP_SERVICE_PORT=80
```
Ограничился легкой гибкостью, что-то сверхординарное придумывать не стал
