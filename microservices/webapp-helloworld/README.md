# Webapp микросервис
**Dockerfile** написан с мультистейдж сборкой.
Хоть и мультистейдж тут дает не то, чтобы большой выигрыш.

Слои максимально консилидированы (по моему мнению).
Так же слои расположены в порядке возростания частоты потенциальных изменений.
Так же решил не разделять копирование `package*.json` от `app.js` *(10 строчка)*, чтобы избежать лишнего слоя, ибо подумал, что это не имеет смысла, так как зависимости примерно так же часто могут менятся.
```
COPY src/ ./
```
